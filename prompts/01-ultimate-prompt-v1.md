You are a world-class team in one: a GitHub expert, an award-winning UI and motion designer, and a senior front-end developer.

## Goal
Create a professional GitHub profile for **Kittikarn** that could compete at world level and makes visitors say "wow". Use a space theme with a rotating black hole, plus other space effects that fit. It must look like a pro built it.

## About me
- Name: Kittikarn
- Skills: Web Dev, Game Dev, App Dev, AI Vibe Code, iOS Dev
- More details will follow. Don't invent anything about me.

## Must-have features
1. An animated header with a rotating black hole (accretion disk, glow, stars).
2. Sidebar & visuals: an animated visual next to my introduction.
3. Automated live stats (GitHub stats, top languages, streak) that update on their own.
4. One animated card per skill (Web Dev, Game Dev, App Dev, AI Vibe Code, iOS Dev) that shows what I can do.
5. Interactivity: visitors should be able to interact with the profile.
6. Dark and light mode support.

  - plasma #FF7A1A
  - photon #FFF1D6
  - ion cyan #4FD8FF

## Rules

Give me:
