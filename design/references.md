## P0 findings
Reviewed 2026-10-21 by a subagent: 8 profiles from abhisheknaiidu (rzashakeri lists tools only). Seen in screenshots at about 800 px wide in light theme only; not checked at desktop or 375 px.
- **natemoo-re**: borrow the `prefers-color-scheme` handled inside its SVG, fixed `<img>` width/height and an empty `<tr></tr>` to hide the gray table row. Avoid: its top-tracks endpoint 404s and shows broken images.
- **novatorem**: borrow one centered "orchestrator" card with equalizer bars from 4 keyframes. Avoid: a ~100 KB SVG for a 300×75 card.
- **rossjrw**: borrow the Issues game (Royal Game of Ur), which uses prefilled `issues/new?title=…` links, a board SVG renamed per issue to bust the cache, and logs in `<details>`. Avoid: a dead build badge and broken avatars.
- **HFO4**: borrow playable PNG controls that redirect back via `callback=`. Avoid: the game depends entirely on a third-party server staying up.
- **BrunnerLivio**: borrow the guestbook rebuilt from comments on one pinned issue, and tiny single-keyframe SVG headings. Avoid: `style=` attributes (GitHub strips them) and mixed GIFs with no shared art direction.
- **MacroPower**: borrow a transparent stats SVG set `align="right"` beside a list, generated by its own Action. Avoid: the text column gets squeezed at narrow widths.
- **andyruwruw**: borrow foreignObject plus CSS-keyframe bars, with art embedded as base64. Avoid: it froze the live API into snapshots, and one asset is 2.2 MB.
- **fnky**: borrow a retro layout that keeps one tone. Avoid: its glitch.me hit counter is dead and shows its alt text.
- **Pattern:** every third-party live service in the set died or was frozen. Self-host the generators in Actions, commit the SVGs, and write alt text that degrades gracefully.
- **Pattern:** the best loops are just prefilled issue links, an Action and a committed SVG. Bust the image cache by renaming files, not with query strings.
- **Pattern:** none of the 8 uses `<picture>`, and none of the SVGs checked handles `prefers-reduced-motion`. Doing both well is where we can lead.
- **Pattern:** failure modes are SVGs of 100 KB to 2.2 MB, dead badges and side-by-side layouts that squeeze. Budget every asset; test at 375 px in both themes.
